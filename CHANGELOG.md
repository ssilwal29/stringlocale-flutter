# Changelog

## 0.2.0

- Added preferred `dynamicText()` and `pluralText()` APIs with backward-compatible aliases.
- Expanded Flutter demo coverage for static text, dynamic text, plural text, formatting, and locale switching.
- Added broader locale digit formatting support.
- Added `dart run stringlocale:compile --init` to scaffold `tool/compile_locales.dart`.
- Improved package documentation and public API Dartdoc coverage.
